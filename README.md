# Bubbly's Dreamy Birthday — Final Package

This version includes the supplied photos, the supplied memory video, and the supplied song file.

## Included
- 14-scene mobile-first birthday experience
- Upright portrait handling for the three sideways couple photos, keeping both faces visible
- Real photo scrapbook memories
- Supplied MP4 memory video
- Supplied `Kanavellam Neethane` MP3 with play/pause/mute controls
- Cute original white + cocoa-brown plush-bear duo for the YES/NO question scene
- Heart-framed QR sharing UI
- `QR_CODE.html` for generating a final QR from the hosted website address
- GitHub Pages compatible static files

## One hosting step
Upload the contents of this folder to a GitHub Pages repository. After GitHub Pages is enabled, open `QR_CODE.html` from the live site and it automatically encodes the live website URL.

The main site also has a **Share & QR** button. It uses the actual live URL, so no URL needs to be typed manually.

No paid API is used. The QR library and GSAP are loaded from public CDNs.
